# Проекты для резюме

Ниже — готовые формулировки без неподтверждённых чисел. После полного запуска ноутбуков можно добавить фактические метрики качества.

## Основные проекты

### Гибридная рекомендательная система для музыкального сервиса

- Построил прототип рекомендаций на данных Yambda: разреженная user-item матрица, user-based collaborative filtering и content-based поиск по эмбеддингам треков.
- Реализовал взвешивание взаимодействий, исключение уже просмотренного контента и объединение кандидатов методом Reciprocal Rank Fusion.
- Подготовил расчёт покрытия каталога и план временной offline-валидации по Recall@K/NDCG@K.

**Стек:** Python, pandas, NumPy, SciPy, scikit-learn, Hugging Face Datasets.

### Интерпретируемая мультиязычная классификация токсичности

- Настроил batched inference XLM-R и оценку качества по языкам на MultiHateCheck.
- Реализовал интерпретацию предсказаний методом occlusion с визуализацией вклада отдельных слов.
- Ограничил оценку заявленной областью применения модели и описал риски переноса на новые языки и домены.

**Стек:** PyTorch, Transformers, scikit-learn, pandas, seaborn.

### Детектор фишинговых писем

- Разработал pipeline бинарной классификации писем на основе TF-IDF и линейных моделей.
- Обнаружил и устранил прямую утечку целевой метки из шаблона входного текста; добавил дедупликацию до разбиения.
- Сравнил модели по F1, ROC-AUC, PR-AUC и MCC, подготовил анализ матрицы ошибок и выбор порога под стоимость ошибок.

**Стек:** Python, scikit-learn, pandas, Hugging Face Datasets.

### Маскирование персональных данных

- Подготовил fine-tuning T5 для преобразования исходного текста в текст с типизированными PII-тегами.
- Реализовал оценку precision/recall/F1 по мультимножеству тегов и строгий exact match.
- Добавил безопасную синтетическую замену замаскированных сущностей с помощью Faker.

**Стек:** PyTorch, Transformers, Hugging Face Datasets, Faker.

## Дополнительные проекты

- **Русскоязычное перефразирование:** seq2seq-генерация, BLEU/ROUGE относительно эталона и отдельная оценка сохранения смысла.
- **Оценка машинного перевода FR → EN:** MarianMT, пакетный инференс, SacreBLEU, TER, chrF++ и BERTScore.
- **Корректор русскоязычных опечаток:** шумовой канал, расстояние редактирования, биграммная языковая модель, WER/CER.
- **Детоксификация русского текста:** генеративное преобразование, оценка снижения токсичности и сохранения семантики.
- **Классификация поддельных отзывов на бенгальском:** работа с дисбалансом, сравнение ComplementNB и Logistic Regression.
- **Стилометрическая идентификация автора:** символьные n-граммы, Linear SVM, проверка устойчивости к опечаткам и анализ характерных паттернов.
